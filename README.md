Hi guys! @ultimategab here 👋

So... this is just a personal project of mine, created mainly for fun and learning, and now I decided to make it public.
I got a lot of inspiration for this project from Shezzor’s videos and a bunch of other tutorials on YouTube. Since he stopped posting videos, I figured I’d keep going on my own and see how far I could take it.
It’s still a work in progress, and there’s plenty more I want to add. It’s not a perfect recreation of the original, but I’d say it’s pretty close. Anyway, feel free to give it a try and have fun!

Gameplay & Controls

Just a heads-up: the game currently supports multiplayer only, so you'll need another player to play.
You can find the game's control configuration in src/config/controls.js.
You can also force the stage you want to play in src/constants/stage.js.
It's possible to change the game's aspect ratio in style.css
